# Tenet v1.4.0

**Tenet** 是面向 C++ 团队的 **规矩 + AI 引导** 元层包（不是带固定架构的脚手架）。本仓库 **不含业务 C++**；工程形状在用户自己的仓库中通过 G0 → Discovery → G1 → Delivery 长出。

**Authority:** [`tenet/AGENTS.md`](tenet/AGENTS.md) · **Start:** [`tenet/process/OVERVIEW.md`](tenet/process/OVERVIEW.md) · **License:** MIT

## 使用方式

1. 拷贝或 submodule 仓库中的 **`tenet/`**（保留 LICENSE）。
2. 在业务仓根写 **胶水** `AGENTS.md`，指向 `./tenet/AGENTS.md`（见 OVERVIEW）。
3. 从 [`for-newcomers`](tenet/adoption/for-newcomers.md) 或 [`prompts/g0-start`](tenet/process/prompts/g0-start.md) 开始。
