# Scrum 最小仪式（Minimal Scrum）

Tenet **不** 展开完整 Scrum 培训。G1 基线中若选定 **Scrum**，用本节 + [`choose-scrum-kanban.md`](../delivery/choose-scrum-kanban.md) 即可。

| 仪式 | 最小做法 |
|------|----------|
| **迭代** | 长度在 baseline 写明（常见 2–4 周） |
| **计划** | 从 backlog 选本迭代项；每项写 **验收**（配合 [`delivery-item.md`](../prompts/delivery-item.md)） |
| **每日** | 可选；小团队可省略 |
| **Review** | 演示 **满足 DoD** 的增量（见 [`definition-of-done.md`](../delivery/definition-of-done.md)） |
| **Retro** | 改 **流程/工具**，不 silent 改架构（架构 → ADR/G2） |

AI：不虚构 Sprint 编号，除非项目已定义。
