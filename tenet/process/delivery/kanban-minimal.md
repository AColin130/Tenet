# Kanban 最小仪式（Minimal Kanban）

Tenet **不** 绑定 Jira/Trello。G1 基线中若选定 **Kanban**，用本节 + [`choose-scrum-kanban.md`](../delivery/choose-scrum-kanban.md) 即可。

| 要素 | 最小做法 |
|------|----------|
| **列** | 至少：待办 → 进行中 → 完成（baseline 可写细） |
| **WIP 限制** | 在 baseline 写明（如进行中 ≤ 2） |
| **卡片** | 一项工作 + **验收**；用 [`delivery-item.md`](../prompts/delivery-item.md) |
| **完成** | 进「完成」列前满足 [`definition-of-done.md`](../delivery/definition-of-done.md) |

AI：**不** 强行套 Sprint / Sprint Planning。
